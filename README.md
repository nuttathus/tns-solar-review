# TNS Solar · ห้องรีวิวสื่อก่อนโพสต์

เว็บสำหรับทีม TNS Solar ใช้ดูภาพ คลิป และแคปชั่นก่อนโพสต์ลง Facebook / TikTok จริง

- `index.html` — หน้าเว็บ
- `data.js` — รายการชุดคอนเทนต์ทั้งหมด (ชุดใหม่ให้เพิ่มไว้บนสุด) สถานะ: `review` รอรีวิว · `approved` อนุมัติแล้ว · `posted` โพสต์แล้ว
- `c/<ชื่อชุด>/` — ไฟล์ของแต่ละชุด (`img/` ภาพ, `v/` คลิปย่อ 720p, `p/` ภาพปกคลิป)

ลิงก์ตรงไปที่ตอนใดตอนหนึ่ง เช่น `…/#solar20/ep05`

คลิปบนเว็บเป็นไฟล์ย่อขนาดสำหรับดูตัวอย่าง ไฟล์เต็มสำหรับโพสต์จริงอยู่ในโฟลเดอร์ TNS Solar บนเครื่อง Windows
