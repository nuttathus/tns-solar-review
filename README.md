# TNS Solar · ห้องรีวิวสื่อก่อนโพสต์

เว็บสำหรับทีม TNS Solar ใช้ดูภาพ คลิป แคปชั่น และสคริปต์พากย์ ก่อนโพสต์ลง Facebook / TikTok จริง

- `index.html` — หน้าเว็บ
- `data.js` — รายการชุดคอนเทนต์ทั้งหมด (ชุดใหม่ให้เพิ่มไว้บนสุด)
  - `group`: `video` วิดีโอ · `post` โพสต์โซเชียล · `print` โบรชัวร์ & ป้าย
  - `status`: `review` รอรีวิว · `approved` อนุมัติแล้ว · `posted` โพสต์แล้ว · `archive` คลังสื่อ
- `c/<ชื่อชุด>/` — ไฟล์ของแต่ละชุด (`v/` คลิปย่อ 720p, `p/` ภาพปกคลิป, `i/` ภาพ, `t/` ภาพย่อสำหรับหน้ารวม)

ลิงก์ตรงไปที่ชิ้นใดชิ้นหนึ่ง เช่น `…/#solar20/ep05` หรือ `…/#people/n01`

คลิปและภาพบนเว็บเป็นไฟล์ย่อขนาดสำหรับดูตัวอย่าง ไฟล์เต็มสำหรับโพสต์/พิมพ์จริงอยู่ในโฟลเดอร์ TNS Solar บนเครื่อง Windows
